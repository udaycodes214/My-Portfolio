# My Portfolio Website

Personal portfolio website built during my **14-day Web Development Internship** at **CODOMAX DIGITAL SOLUTION**.

This project was developed step-by-step following a structured daily task plan covering HTML, CSS, JavaScript, responsiveness, and deployment.

## Live Demo
(https://udaycodes214.github.io/My-Portfolio/)

## Internship Progress (Day-wise)

| Day | Task |
|-----|------|
| **Day 1** | Installed VS Code, Git, Chrome extensions, created GitHub account & initialized repository |
| **Day 2** | Learned HTML basics and built Home, Hero & About sections |
| **Day 3** | Created semantic HTML, navigation, skills, education, contact form & footer |
| **Day 4** | Styled the website using CSS (typography, colors, spacing, buttons & layout) |
| **Day 5** | Built responsive layouts using Flexbox and CSS Grid |
| **Day 6** | Applied Media Queries and optimized for mobile, tablet & desktop |
| **Day 7** | Learned JavaScript basics – button events, DOM manipulation & scroll-to-top |
| **Day 8** | Developed Projects section with project cards |
| **Day 9** | Created Skills, Resume Download & Experience sections |
| **Day 10** | Built professional Contact page with social links & form validation |
| **Day 11** | Added animations, transitions, hover effects & smooth scrolling |
| **Day 12** | Used Git commands, pushed code & deployed with GitHub Pages |
| **Day 13** | Tested responsiveness, fixed bugs, optimized performance & cleaned code |
| **Day 14** | Final submission – GitHub repository, live website, README & documentation |

## Features
- Fully responsive design (Mobile, Tablet & Desktop)
- Smooth scrolling navigation
- Interactive sections with hover effects and animations
- Downloadable Resume
- Contact form with validation
- Project showcase cards
- Clean and modern UI

## Tech Stack
- **HTML5** (Semantic structure)
- **CSS3** (Flexbox, Grid, Media Queries, Animations)
- **JavaScript** (DOM Manipulation, Events, Smooth Scroll)
- Font Awesome
